# 生财之道（刷钱方法）

> [演示视频](https://www.youtube.com/watch?v=E2z2r5drko8)

------

赚钱地点是天堂防卫区域那个无限吐火炎霍洛钢的蛋头甲兵处。

要点：

1. 要有 SP 级装甲(标上「不容易倒下」的皆可)
2. 真空手臂全改造
3. 先让蛋头甲兵只剩一个
4. 然后站在墙壁旁...那个有角度的
5. 清除目前全部的火炎霍洛钢(这样会让等会的赚钱更有效率)
6. 最后只要按着特武键就好了

若站的位置对，火炎霍洛钢撞到洛克后就会往墙角走。

然后因为又撞到洛克而卡在墙角(几乎100%)，就被夹爆了...

然后能源矿一出来就被真空手臂吸走！

这时可以找重物来压住按键，去做些杂事

慢慢地...钱就来越多啦！

![](./money.jpg)

不过还要注意一个情况：

- 当二个以上火炎霍洛钢同时使用冲刺撞击的话，洛克会被撞飞
- 当地图上火炎霍洛钢太多时，这种情况发生的机率有点高，所以要先让蛋头甲兵只剩一个
- 之后就不容易发生了，但还是有极低的可能性
